# Mark Angelo Pene — Portfolio

## Open in VS Code
1. Extract this ZIP.
2. In VS Code, choose **File → Open Folder** and select `mark_angelo_portfolio`.
3. Keep this structure intact:
   - `index.html`
   - `styles.css`
   - `script.js`
   - `assets/portrait.png`
4. Open `index.html` in a browser, or install the **Live Server** extension in VS Code and click **Go Live**.

## Before publishing
- Replace `your.email@example.com` in `index.html` with your professional email.
- Replace the GitHub and LinkedIn `href="#"` links with your real profile URLs, or remove them if you do not use those platforms.
- Confirm the listed technologies are ones you can explain and demonstrate.
- Add project screenshots and more detailed descriptions when ready.
- SAP 1 and SAP 2 are described as school-provided academic training, not verified external certifications.

The portrait file is `assets/portrait.png`. Do not rename or move it unless you also update its path in `script.js`.
The binary portrait effect uses HTML Canvas and JavaScript. Google Fonts load online; fallback fonts are provided.
